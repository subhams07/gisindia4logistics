# Railway Station & Category State Review (PR #18 -> PR #29)

This directory records the complete, resolved audit trail for the two railway-station state review lists generated by [`scripts/clean/assign_station_states.py`](../../scripts/clean/assign_station_states.py):

- [`railway_station_state_review.csv`](railway_station_state_review.csv) — **189 rows** (all resolved; `0` unresolved)
- [`station_category_state_review.csv`](station_category_state_review.csv) — **42 rows** (all resolved; `0` unresolved)

Every resolution was verified against OpenStreetMap (`railway=station` / `railway=halt` nodes via Nominatim and Overpass) and Survey of India LGD polygons (`data/administrative/india_states_lgd.geojson`, checked via `build_gct_terminals.in_state()`). Rerunning `scripts/clean/assign_station_states.py` preserves resolved `resolution` and `note` records idempotently while surfacing any newly introduced disagreements.

## Key Rulings & Edge Cases

- **Bangladesh Maitree Express (`DSN`, `DHCA`) — Maintainer Ruling (2026-11-24):** `DSN` (Darsana, Chuadanga District) and `DHCA` (Dhaca Cantt., Dhaka Cantonment) are legitimate international Maitree Express stations in Bangladesh. Their Bangladesh coordinates are retained verbatim in `data/rail/railway_stations.csv`, their Indian `state` field stays blank, and `INTERNATIONAL_STATIONS = {"DSN", "DHCA"}` in `scripts/clean/assign_station_states.py` excludes them from India-polygon errors.
- **`TDK` Code Collision (`station_category_state_review.csv`):** The `station_categories.csv` row (`Tadoki`, `SECR/R`, Antagarh, Kanker, Chhattisgarh) refers to Indian Railways station code **`TDOK`** mis-coded as `TDK` in the upstream community classification table, colliding with `TDK` = **Taduku** (Tirupati, Andhra Pradesh, real zone `SR/MAS`, verified on OSM at `13.49736, 79.53032`). The two rows are different physical stations and are not merged (note that `railway_stations.csv` row `TDK` also inherited `zone=SECR`/`division=R` from this upstream collision).
- **SoI Border-Straddling Stations (`RUPC`, `DLW`):**
  - `RUPC` (Rudrapur City): Both the existing coordinate (`28.96928, 79.37921`) and OSM `railway=station` (`28.96954, 79.37980`, 0.06 km away) lie ~95–142 m south of the Uttarakhand border inside `Dibdiba (CT)`, Bilaspur, Rampur, **Uttar Pradesh** in both SoI ABDB and unsimplified SoI village polygons, although the station serves Rudrapur city in Uttarakhand.
  - `DLW` (Dilwa): OSM `railway=station` (`24.53798, 85.41956`, 0.07 km from existing coord) falls inside `Delwa`, Nawada, Bihar in SoI village polygons, but 19.7 m (existing coord 75.1 m) south of the SoI 1:50k ABDB state line inside Koderma, **Jharkhand** (within ABDB ±12.5 m RMSE). `station_categories.csv` is aligned to `Jharkhand` to remain consistent with `india_states_lgd.geojson`.
